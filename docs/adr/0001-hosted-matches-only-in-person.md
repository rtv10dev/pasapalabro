# Hosted Matches are played in one room only

A Hosted Match needs Players to hear the Host and the app to hear each Player's answer. Remotely, that means either carrying the Host's voice in-app (WebRTC audio) or relying on an outside call, where Players' microphones pick up the Host through their speakers and phones fight over the mic. We decided Hosted Matches are in-person only, and remote Matches always use the app's synthesized voice to read Clues. Remote Hosts are a deliberate omission, not a missing feature.
